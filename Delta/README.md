# Delta Lake

En esta sección se evalúa Delta Lake, una capa de almacenamiento de código abierto que aporta fiabilidad a los lagos de datos (Data Lakes). Delta Lake proporciona transacciones ACID, manejo de metadatos escalable y unifica el procesamiento de datos por lotes (batch) y en streaming.

## Objetivos

* Integración de Delta Lake con Apache Spark.
* Operaciones ACID (Time Travel, UPDATE/DELETE/MERGE).
* Evaluación del transaction log (`_delta_log`).

## Dependencias

* Apache Spark
