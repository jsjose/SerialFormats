# Apache Parquet

Este directorio está dedicado a explorar Apache Parquet, un formato de almacenamiento de datos columnar de código abierto diseñado para una compresión y codificación de datos eficiente.

## Objetivos de las pruebas

* Lectura y escritura de ficheros `.parquet` usando Python (pandas, pyarrow).
* Evaluación del rendimiento en consultas analíticas frente a formatos orientados a filas (como CSV o JSON).
* Comprensión del particionado y esquemas anidados.
